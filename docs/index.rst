KickLLM cost reference
======================

`KickLLM <https://kickllm.com/>`_ is a free LLM API pricing calculator: it compares
per-token prices for 24 models from 9 providers and converts them into a monthly
spend estimate or a per-conversation cost.

This documentation explains the arithmetic behind those numbers, which inputs move
the result most, and where a token-price comparison stops being useful.
